# LaTex_guia

# 📕Que es?

LaTeX (se pronuncia "lah-tech" o "lay-tech") es un sistema para crear documentos de alta calidad tipográfica. A diferencia de Word, no ves el resultado final mientras escribís: escribís código con instrucciones y LaTeX lo convierte en un PDF perfecto.

# 💻Para que sirve?

**Documentos académicos** :
Tesis, papers, artículos científicos, libros

**Fórmulas y ecuaciones** :
Sin rival para expresiones matemáticas complejas

**Presentaciones** :
Con el paquete Beamer (tipo PowerPoint)

**Bibliografía automática** :
Referencias y citas se gestionan solas

# Como funciona?

El flujo es siempre el mismo: escribís un archivo de texto plano con extensión .tex, lo compilás, y obtenés un .pdf perfecto.
